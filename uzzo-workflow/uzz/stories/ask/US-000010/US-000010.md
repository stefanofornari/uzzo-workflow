## ask/US-000010 — Tell the Model When the User Has No Answer

### User Story

```
AS A Developer
I WANT a way to signal that the user gave no answer that the model can see
SO THAT the agent can go on, rephrase or choose a default instead of failing
```

#### Status
WIP

#### Dependencies
- None

#### Technical Context & Constraints
* **Target System**: Any JVM host application that embeds the Uzzo Workflow library (e.g. ViberFX, ViberCLI)
* **Toolchain / Rules**: Java 21, Maven, LangChain4j 1.21.0; coding standard `uzz/project/coding_standard.md`; development framework `uzz/project/development_framework.md`

#### Notes
1. `NoAnswerException` is a `RuntimeException` that implements LangChain4j's `ToolErrorVisibleToLlm`; its message, also returned by `messageForLlm()`, defaults to `<NO ANSWER PROVIDED>`.
2. The descriptions of the four `AskTools` tools tell the model that this marker is returned when the user has no answer.
3. The exception is covered by tests; the tool descriptions are not, hence the WIP status.

### Acceptance Criteria

```gherkin
Scenario: Exception without message
  Given the Developer creates a NoAnswerException without a message
  When  the Developer reads getMessage and messageForLlm
  Then  both are "<NO ANSWER PROVIDED>"

Scenario: Exception with a null message
  Given the Developer creates a NoAnswerException with a null message
  When  the Developer reads getMessage and messageForLlm
  Then  both are "<NO ANSWER PROVIDED>"

Scenario: Exception with a custom message
  Given the Developer creates a NoAnswerException with the message "custom message"
  When  the Developer reads getMessage and messageForLlm
  Then  both are "custom message"

Scenario: Exception is visible to the model
  Given a NoAnswerException thrown by an AskTools implementation
  When  LangChain4j handles the tool error
  Then  the message is passed to the model, because the exception implements ToolErrorVisibleToLlm

Scenario: Tool descriptions mention the marker
  Given the AskTools contract
  When  the Developer reads the descriptions of the four tools
  Then  each of them mentions "<NO ANSWER PROVIDED>"
```
