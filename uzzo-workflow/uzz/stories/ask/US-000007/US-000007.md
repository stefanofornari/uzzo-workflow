## ask/US-000007 — Let the Agent Ask the User an Open-Ended Question

### User Story

```
AS A Developer
I WANT to plug my own implementation of the AskQuestion tool into an agent
SO THAT the agent can collect missing information as free text through my application's own interface (CLI, GUI, web)
```

#### Status
DONE

#### Dependencies
- None

#### Technical Context & Constraints
* **Target System**: Any JVM host application that embeds the Uzzo Workflow library (e.g. ViberFX, ViberCLI)
* **Toolchain / Rules**: Java 21, Maven, LangChain4j 1.21.0; coding standard `uzz/project/coding_standard.md`; development framework `uzz/project/development_framework.md`

#### Notes
1. `AskTools` is a contract only; the library ships no implementation. The Developer implements it for the platform of the host application.
2. `AskTools` extends `ste.llm.tools.Tool` and exposes `askQuestion` as the LangChain4j tool `AskQuestion`.
3. The tests use a mock implementation (`MockAskTools`) registered with `AiServices.tools(...)`.

### Acceptance Criteria

```gherkin
Scenario: Agent asks a question
  Given an agent built with the Developer's AskTools implementation
  When  the model requests the tool AskQuestion
  Then  askQuestion of the Developer's implementation is invoked with the question
  And   the returned text is given back to the model

Scenario: Agent has no gaps to clarify
  Given an agent built with the Developer's AskTools implementation
  When  the Developer sends a prompt that needs no clarification
  Then  no AskTools method is invoked
```
