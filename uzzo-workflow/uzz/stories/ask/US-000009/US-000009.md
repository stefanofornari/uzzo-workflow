## ask/US-000009 — Let the Agent Ask the User for Confirmation

### User Story

```
AS A Developer
I WANT to plug my own implementation of the AskConfirmation tool into an agent
SO THAT the agent can get an explicit yes/no decision from the user before it goes on
```

#### Status
WIP

#### Dependencies
- ask/US-000010

#### Technical Context & Constraints
* **Target System**: Any JVM host application that embeds the Uzzo Workflow library (e.g. ViberFX, ViberCLI)
* **Toolchain / Rules**: Java 21, Maven, LangChain4j 1.21.0; coding standard `uzz/project/coding_standard.md`; development framework `uzz/project/development_framework.md`

#### Notes
1. `askConfirmation(question)` returns a boolean; the tool name is `AskConfirmation`.
2. Covered by `AskConfirmationToolTest`; the story stays WIP until the tests have been run and are green.

### Acceptance Criteria

```gherkin
Scenario: User confirms
  Given an agent built with the Developer's AskTools implementation
  When  the model requests the tool AskConfirmation with a question
  Then  askConfirmation of the Developer's implementation is invoked with the question
  And   true is given back to the model when the user confirms

Scenario: User declines
  Given an agent built with the Developer's AskTools implementation
  When  the model requests the tool AskConfirmation and the user declines
  Then  false is given back to the model

Scenario: User has no answer
  Given an agent built with the Developer's AskTools implementation
  When  the Developer's askConfirmation throws a NoAnswerException
  Then  the model is told "<NO ANSWER PROVIDED>"
```
