# Users

Actors referenced by the `AS A [role]` clause of user stories. This list is
authoritative: stories must not invent roles that are not listed here. Add a
role only when the project genuinely has it.

- **Developer**: a developer embedding the Uzzo Workflow library in another tool or application. The library has no end-user interface of its own, so the Developer is the user: they build the agents, supply the chat model, memory and tools, and implement user interaction for their platform.
