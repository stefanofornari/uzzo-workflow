## skill/US-000006 — Get a Skill-Bound Agent Builder for Each Workflow Action

### User Story

```
AS A Developer
I WANT a ready-made builder for each of the scope, story and code agents
SO THAT I only add my chat model, memory and tools to get a working agent
```

#### Status
DONE

#### Dependencies
- skill/US-000004
- agent/US-000001
- agent/US-000002
- agent/US-000003

#### Notes
1. Target system: Any JVM host application that embeds the Uzzo Workflow library (e.g. ViberFX, ViberCLI). Toolchain and rules: Java 21, Maven, LangChain4j 1.21.0; coding standard `uzz/project/coding_standard.md`; development framework `uzz/project/development_framework.md`.
2. `UzzoAgentBuilder` exposes `ScopeAgentBuilder()`, `StoryAgentBuilder()` and `CodeAgentBuilder()`; each returns a LangChain4j `AiServices` already bound to its skill.
3. The chat model, chat memory and tools are not set by the builders: the host adds them before calling `build()`.
4. Each builder also has an overload taking an `AgentSystemMessage`, so that a host (or a test) can change where skills are resolved from; the no-argument builders use the classpath.
5. Covered by `UzzoAgentBuilderTest`, one test per builder and scenario.
6. Verified by the tests: the `IllegalStateException` is thrown by the agent method call itself (where LangChain4j resolves the system message), not later when the `TokenStream` is started.

### Acceptance Criteria

```gherkin
Scenario Outline: Builder binds the agent to its skill
  Given the Developer calls <builder> of UzzoAgentBuilder
  When  the Developer adds a streaming chat model, builds the agent and invokes it
  Then  the system prompt sent to the model is taken from <skill>

  Examples:
    | builder             | skill                    |
    | ScopeAgentBuilder() | uzz/skills/scope/SKILL.md |
    | StoryAgentBuilder() | uzz/skills/story/SKILL.md |
    | CodeAgentBuilder()  | uzz/skills/code/SKILL.md  |

Scenario: Skill is missing from the classpath
  Given a classpath without the skill of the chosen builder
  When  the Developer builds the agent and invokes it
  Then  the invocation fails with an IllegalStateException about the missing system prompt resource
```
