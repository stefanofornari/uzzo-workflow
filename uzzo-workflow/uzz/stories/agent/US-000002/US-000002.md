## agent/US-000002 — Ask the Story Agent to Generate or Update User Stories

### User Story

```
AS A Developer
I WANT to send a request, together with the scope and persona context, to the story agent
SO THAT the agent generates or updates INVEST-compliant user stories from my scope without my application building the prompt logic
```

#### Status
DONE

#### Dependencies
- skill/US-000004

#### Technical Context & Constraints
* **Target System**: Any JVM host application that embeds the Uzzo Workflow library (e.g. ViberFX, ViberCLI)
* **Toolchain / Rules**: Java 21, Maven, LangChain4j 1.21.0; coding standard `uzz/project/coding_standard.md`; development framework `uzz/project/development_framework.md`

#### Notes
1. Entry point `UzzoStoryAgent.stories(String)`: it validates the input and then delegates to `_stories_`, the method implemented by LangChain4j AI Services.
2. The system prompt is the `uzz/skills/story/SKILL.md` skill; the chat model, chat memory and tools are provided by the host when it builds the agent (see skill/US-000006).
3. The reply is a LangChain4j `TokenStream`; the Developer decides how to consume it (partial responses, completion, errors).
4. The request carries the available scope and persona context as text; the story skill defines how the stories are written.

### Acceptance Criteria

```gherkin
Scenario: Developer sends a well-formed request
  Given a UzzoStoryAgent built with a streaming chat model
  When  the Developer calls stories with a non-blank text
  Then  a TokenStream is returned
  And   the first message sent to the model is the system prompt taken from the uzz/skills/story/SKILL.md skill

Scenario Outline: Developer sends a blank request
  Given a UzzoStoryAgent built with a streaming chat model
  When  the Developer calls stories with <input>
  Then  an IllegalArgumentException is thrown
  And   no request is sent to the model

  Examples:
    | input                 |
    | null                  |
    | an empty string       |
    | only whitespace       |
```
