## agent/US-000001 — Send a Prompt to the Scope Agent and Receive a Streamed Reply

### User Story

```
AS A Developer
I WANT to send a free-text prompt to the scope agent and receive its reply as a stream
SO THAT my application can run the scope clarification dialogue and show the agent's answer while it is produced
```

#### Status
DONE

#### Dependencies
- skill/US-000004

#### Notes
1. Target system: Any JVM host application that embeds the Uzzo Workflow library (e.g. ViberFX, ViberCLI). Toolchain and rules: Java 21, Maven, LangChain4j 1.21.0; coding standard `uzz/project/coding_standard.md`; development framework `uzz/project/development_framework.md`.
2. Entry point `UzzoScopeAgent.scope(String)`: it validates the input and then delegates to `_scope_`, the method implemented by LangChain4j AI Services.
3. The system prompt is the `uzz/skills/scope/SKILL.md` skill; the chat model, chat memory and tools are provided by the host when it builds the agent (see skill/US-000006).
4. The reply is a LangChain4j `TokenStream`; the Developer decides how to consume it (partial responses, completion, errors).
5. The first call carries the project or feature prompt; later calls continue the dialogue using the conversation history kept by the chat memory the host configures. A rejected blank message does not affect later valid calls.

### Acceptance Criteria

```gherkin
Scenario: Developer sends a well-formed request
  Given a UzzoScopeAgent built with a streaming chat model
  When  the Developer calls scope with a non-blank text
  Then  a TokenStream is returned
  And   the first message sent to the model is the system prompt taken from the uzz/skills/scope/SKILL.md skill

Scenario Outline: Developer sends a blank request
  Given a UzzoScopeAgent built with a streaming chat model
  When  the Developer calls scope with <input>
  Then  an IllegalArgumentException is thrown
  And   no request is sent to the model

  Examples:
    | input                 |
    | null                  |
    | an empty string       |
    | only whitespace       |
```
