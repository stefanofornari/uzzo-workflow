## agent/US-000003 — Ask the Code Agent to Implement a User Story

### User Story

```
AS A Developer
I WANT to send a request containing the user story to implement to the code agent
SO THAT the agent drives the implementation from specification to tested code using the project context in the knowledge base
```

#### Status
DONE

#### Dependencies
- skill/US-000004

#### Notes
1. Target system: Any JVM host application that embeds the Uzzo Workflow library (e.g. ViberFX, ViberCLI). Toolchain and rules: Java 21, Maven, LangChain4j 1.21.0; coding standard `uzz/project/coding_standard.md`; development framework `uzz/project/development_framework.md`.
2. Entry point `UzzoCodeAgent.implement(String)`: it validates the input and then delegates to `_implement_`, the method implemented by LangChain4j AI Services.
3. The system prompt is the `uzz/skills/code/SKILL.md` skill; the chat model, chat memory and tools are provided by the host when it builds the agent (see skill/US-000006).
4. The reply is a LangChain4j `TokenStream`; the Developer decides how to consume it (partial responses, completion, errors).
5. The request identifies the user story to implement (e.g. its ID) and any additional context.

### Acceptance Criteria

```gherkin
Scenario: Developer sends a well-formed request
  Given a UzzoCodeAgent built with a streaming chat model
  When  the Developer calls implement with a non-blank text
  Then  a TokenStream is returned
  And   the first message sent to the model is the system prompt taken from the uzz/skills/code/SKILL.md skill

Scenario Outline: Developer sends a blank request
  Given a UzzoCodeAgent built with a streaming chat model
  When  the Developer calls implement with <input>
  Then  an IllegalArgumentException is thrown
  And   no request is sent to the model

  Examples:
    | input                 |
    | null                  |
    | an empty string       |
    | only whitespace       |
```
