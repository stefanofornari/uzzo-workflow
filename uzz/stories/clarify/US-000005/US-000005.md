## clarify/US-000005 — Present Clarifying Questions in Paced Clusters

### User Story

```
AS A Developer
I WANT the Scope Agent to present clarifying questions one by one or in small clusters of at most three
SO THAT I am not overwhelmed and can provide thoughtful, accurate answers to each question
```

#### Technical Context & Constraints
* **Target System**: ViberFX desktop application / ViberCLI terminal interface
* **Toolchain / Rules**: Java, JavaFX, Maven; Viber `Viber`-`Actor` framework; coding standard `uzz/specs/coding_standard.md`; development framework `uzz/specs/development_framework.md`

#### Notes
1. Maximum cluster size is 3 questions per interaction turn.
2. The agent must wait for the Developer's answers before presenting the next cluster.
3. If only 1 question remains, it is presented alone — no padding with unrelated questions.

### Acceptance Criteria

```gherkin
Scenario: Multiple gaps — questions presented in clusters of at most 3
  Given the agent has 7 clarifying questions ready
  When  the agent presents the first cluster
  Then  at most 3 questions are shown to the Developer
  And   the agent waits for answers before presenting the next cluster

Scenario: Exactly 3 gaps — all shown in one cluster
  Given the agent has exactly 3 clarifying questions ready
  When  the agent presents the first cluster
  Then  all 3 questions are shown
  And   the agent waits for the Developer's response

Scenario: A single remaining question is presented alone
  Given the agent has 1 clarifying question remaining
  When  the agent presents it
  Then  exactly 1 question is shown without artificial padding
```
