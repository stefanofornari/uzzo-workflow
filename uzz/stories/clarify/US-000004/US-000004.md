## clarify/US-000004 — Generate Targeted Clarifying Questions from Gaps

### User Story

```
AS A Developer
I WANT the Scope Agent to generate targeted clarifying questions based on identified gaps
SO THAT I can provide the missing information needed to produce a complete and accurate scope document
```

#### Dependencies
- analysis/US-000003

#### Technical Context & Constraints
* **Target System**: ViberFX desktop application / ViberCLI terminal interface
* **Toolchain / Rules**: Java, JavaFX, Maven; Viber `Viber`-`Actor` framework; coding standard `uzz/specs/coding_standard.md`; development framework `uzz/specs/development_framework.md`

#### Notes
1. Each question must directly target one gap from the categorized gap list (US-000003).
2. Questions must be clear, specific, and neutral — no leading questions.
3. This story is responsible only for generating the questions; pacing and presentation are handled by US-000005.

### Acceptance Criteria

```gherkin
Scenario: Questions generated for each gap
  Given a categorized gap list with N gaps
  When  the agent generates clarifying questions
  Then  exactly N questions are produced (one per gap)
  And   each question directly references its corresponding gap

Scenario: No gaps — no questions generated
  Given a categorized gap list with zero entries
  When  the agent attempts to generate questions
  Then  no questions are generated
  And   the agent proceeds directly to boundary definition

Scenario: Question format is neutral and specific
  Given a gap labeled "target platform assumption"
  When  the agent generates a question for this gap
  Then  the question asks specifically about the target platform without suggesting an answer
```
