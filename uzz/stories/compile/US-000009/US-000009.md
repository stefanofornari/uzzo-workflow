## compile/US-000009 — Generate a Structured Scope Document from the Exact Template

### User Story

```
AS A Developer
I WANT the Scope Agent to generate a structured scope document using the exact template defined in the skill
SO THAT the output is consistent, predictable, and immediately usable without manual reformatting
```

#### Dependencies
- boundary/US-000008

#### Technical Context & Constraints
* **Target System**: ViberFX desktop application / ViberCLI terminal interface
* **Toolchain / Rules**: Java, JavaFX, Maven; Viber `Viber`-`Actor` framework; coding standard `uzz/specs/coding_standard.md`; development framework `uzz/specs/development_framework.md`
* **Template Source**: `uzz/skills/scope/SKILL.md`

#### Notes
1. The template is sourced exclusively from `uzz/skills/scope/SKILL.md` — no deviations are permitted.
2. All mandatory sections must be populated; no section may be left blank or omitted.
3. Document generation is a pure assembly step — no new information is introduced at this stage.

### Acceptance Criteria

```gherkin
Scenario: Document is generated conforming to the template
  Given boundary definition is complete (in-scope and out-of-scope lists are finalized)
  When  the agent generates the scope document
  Then  the output matches the exact section structure defined in the skill template
  And   no section is missing or blank

Scenario: Template structure is not altered
  Given the skill template has specific section headings and ordering
  When  the agent generates the scope document
  Then  section headings and ordering exactly match the template
  And   no extra sections are added

Scenario: No new information is introduced during generation
  Given the finalized in-scope and out-of-scope lists
  When  the agent assembles the document
  Then  every item in the document traces back to information provided by the Developer
  And   no item is invented by the agent
```
