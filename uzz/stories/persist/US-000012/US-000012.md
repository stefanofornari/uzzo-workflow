## persist/US-000012 — Write the Scope Document to a Target Markdown File

### User Story

```
AS A Developer
I WANT the Scope Agent to write the compiled scope document to a specified target markdown file
SO THAT the scope output is persisted and available for future reference without manual copy-paste
```

#### Technical Context & Constraints
* **Target System**: ViberFX desktop application / ViberCLI terminal interface
* **Toolchain / Rules**: Java, JavaFX, Maven; Viber `Viber`-`Actor` framework; coding standard `uzz/specs/coding_standard.md`; development framework `uzz/specs/development_framework.md`

#### Notes
1. The target file path is specified by the Developer.
2. If the target file does not exist, the agent must create it (including parent directories if needed).
3. This story handles only the write-new case; updating an existing file is covered by US-000013.

### Acceptance Criteria

```gherkin
Scenario: Scope document is written to a new target file
  Given the compiled scope document and a target file path that does not yet exist
  When  the agent persists the document
  Then  the file is created at the specified path
  And   the file content matches the compiled scope document exactly

Scenario: Parent directories are created if missing
  Given a target file path whose parent directories do not exist
  When  the agent persists the document
  Then  all required parent directories are created
  And   the file is written successfully

Scenario: Target path is not provided
  Given the agent is ready to persist but no target path was specified
  When  the agent attempts to write
  Then  the agent asks the Developer for the target file path
  And   does not write to any default location without explicit confirmation
```
